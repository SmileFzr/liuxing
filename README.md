# 无尽回响：轮回（Endless Echo · 回合制版）

纯前端、零依赖的回合制 RPG。是 `endless-echo`（实时动作版）的**回合制重制**，拆成 `js/*.js` 多模块加载。

在线试玩：https://smilefzr.github.io/liuxing/

## 本地运行

```bash
# 方式一：起一个静态服务（推荐，避免个别浏览器的本地文件限制）
python -m http.server 8321
# 然后访问 http://localhost:8321

# 方式二：直接双击 index.html
```

手机同 WiFi 可用 `http://<电脑局域网IP>:8321` 打开。

## 目录结构

```
.
├── index.html          # 页面结构（按顺序引入 js/ 下 7 个脚本）
├── style.css           # 全部样式
├── js/
│   ├── data.js         # 【改数值只改这个文件】属性/角色/技能/怪物/12生肖/道具/地图
│   ├── core.js         # 存档、属性计算、经验升级、加点、技能学习、五行克制
│   ├── battle.js       # 回合制战斗：按速度排序、6v6、伤害公式、捕捉、自动战斗
│   ├── explore.js      # 摇杆移动、围墙碰撞、NPC/出口互动、暗雷遇敌
│   ├── ui.js           # 屏幕切换、战斗渲染、日志、队伍/加点/背包/图鉴
│   ├── ui-panels.js    # 商店/药师/神秘人/结算面板、对话框、战斗按钮绑定
│   └── main.js         # 启动与主菜单按钮绑定、主循环
└── tools/
    └── check.js        # 无头自检（Node 里跑通全流程，见下）
```

> 加载顺序不能乱：`data → core → battle → explore → ui → ui-panels → main`。
> 注意 `ui` 是在 `ui.js` 里用 `const` 声明的，所以**任何其他模块都不能在顶层直接给 `ui` 赋值**（会撞上暂时性死区，整包加载失败）。扩展 `ui` 请写进 `ui.js` / `ui-panels.js`。

## 自检（每次改完都跑一遍）

```bash
node tools/check.js
```

它用最小 DOM 桩在 Node 里把整套脚本跑起来，检查：

- 7 个模块语法、合并整包语法
- `index.html` 引用的脚本与**代码里所有 `$('id')` 是否都能在 HTML 找到**（之前的故障就是这类静默失败）
- 新游戏 → 探索 → 遇敌 → 战斗 → 结算 全流程
- 5 场战斗能否正常结束、平均日志条数（防止秒杀）
- 升级发点、加点、技能整档 +5、档位上限
- 捕捉 / 宝宝 / 变异、宠物上场、图鉴、团灭回城扣金币
- 区域推进、王陵 BOSS、轮回保留资产
- 存档 / 读档
- 数值体检：三角色定位（法师蓝多魔攻高、游侠最快、剑士物防最高）

## 已实现的玩法

| 系统 | 说明 |
| --- | --- |
| 回合制战斗 | 每回合按 `spd` 从高到低各行动一次；同速我方优先 |
| 伤害公式 | 物理 `max(1, atk*1.5*技能倍率*五行 - def)`；魔法同式用 `matk/mdef`；防御过高保留 8% 保底 |
| 三角色 | 剑士（物理/防御）、法师（蓝高/魔法）、游侠（速度/控制），各 2 个技能 |
| 技能 | 每 5 级一档（1-9→5，10-14→10，15-19→15…），**找神秘人花金币整档 +5**，不自动涨 |
| 升级加点 | 每级 +5 点，升级只提示不弹窗，队伍按钮亮红点 |
| 出战队伍 | 3 角色 + 最多 3 宠物，**只有上场宠物吃经验** |
| 遇敌 | 暗雷，城镇为安全区；队伍超过 4 人时更容易遇到 6 只 |
| 地图 | **相机跟随玩家**：角色固定在屏幕中心，世界整体平移；城镇有围墙/房屋碰撞（29×20 格） |
| 野外 | **无限平面**：没有边界，可以一直往一个方向走；右上角小地图显示回城与下一区域的方向和距离 |
| 宠物 | 12 生肖怪有几率出「宝宝」「变异」，变异带更强变异技能；非战斗可换宠上场（仓库上限 12） |
| 捕捉 | 血越少越容易；封印符提升成功率；非生肖怪不可捕捉 |
| 自动战斗 | 战斗内 18 秒倒计时，超时自动接管；`🤖 自动` 可随时切换 |
| 自动探索 | 野外 `🚶` 自动来回走并自动打 |
| 图鉴 | 怪物：**进过战斗就算遇到**才展示；宠物：按生肖统计普通/宝宝/变异 |
| 团灭 | 回城复活（半血），扣 5% 金币（最低 10） |
| 轮回 | 击败「沙之支配者」后开启，属性/物品/宠物全部保留，世界变强 |

## 数值调整入口

全部集中在 `js/data.js`：`CLASSES`（三角色成长）、`SKILLS` / `PET_SKILLS`（技能倍率与蓝耗）、`MONSTERS`（怪物基准值与经验金币）、`PETS`（生肖偏科）、`ZONES`（各区域遇敌表与怪物数量）、`RARITY_RATES`（宝宝/变异概率）、`CAPTURE_BASE`（捕捉率）、`ENCOUNTER_STEPS`（遇敌步数）。

战斗公式在 `js/battle.js` 的 `rollDamage()`；属性公式在 `js/core.js` 的 `calcStatsFor()`。
